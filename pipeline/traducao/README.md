# pipeline/traducao

Extração dos textos clínicos do DDInter, glossário, rascunho de tradução com status e memória
com histórico (P8). Documentação completa em [`docs/traducao.md`](../../docs/traducao.md);
decisões na [ADR 0007](../../docs/adr/0007-traducao.md).

```bash
pnpm pipeline:traducao status
pnpm --filter @doctorine/pipeline-traducao traducao --help
```
