# Registros de decisão (ADRs)

Cada decisão técnica que afeta o projeto fica registrada aqui, com contexto, alternativas e
consequências. Uma ADR só vira **Aceita** depois da aprovação do Edu; até lá, fica como **Proposta**.

| ADR                                   | Título                       | Status   |
| ------------------------------------- | ---------------------------- | -------- |
| [0001](0001-stack.md)                 | Stack                        | Proposta |
| [0002](0002-fontes-de-dados.md)       | Fontes de dados              | Proposta |
| [0003](0003-funcionamento-offline.md) | Funcionamento offline        | Proposta |
| [0004](0004-finalidade-e-licencas.md) | Finalidade, licenças e aviso | Proposta |

Formato: Contexto, Decisão, Alternativas consideradas, Consequências. Numeração sequencial; ADR
substituída ganha o status "Substituída por NNNN" e continua no repositório.
