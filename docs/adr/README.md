# Registros de decisão (ADRs)

Cada decisão técnica que afeta o projeto fica registrada aqui, com contexto, alternativas e
consequências. Uma ADR só vira **Aceita** depois da aprovação do Edu; até lá, fica como **Proposta**. As ADRs 0001 a 0004 foram aceitas
em 2026-11-12.

| ADR                                   | Título                       | Status |
| ------------------------------------- | ---------------------------- | ------ |
| [0001](0001-stack.md)                 | Stack                        | Aceita |
| [0002](0002-fontes-de-dados.md)       | Fontes de dados              | Aceita |
| [0003](0003-funcionamento-offline.md) | Funcionamento offline        | Aceita |
| [0004](0004-finalidade-e-licencas.md) | Finalidade, licenças e aviso | Aceita |

Formato: Contexto, Decisão, Alternativas consideradas, Consequências. Numeração sequencial; ADR
substituída ganha o status "Substituída por NNNN" e continua no repositório.
