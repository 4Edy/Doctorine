# Aviso de uso

O Doctorine é um projeto de **estudo e uso pessoal**, feito para apoiar o trabalho de uma
farmacêutica. Não é vendido, não é distribuído em loja e não tem cadastro de pacientes.

1. **Apoio, não decisão.** O app organiza informação de fontes públicas. A decisão clínica é sempre
   do profissional, com o paciente e com as referências oficiais.
2. **Ausência não é segurança.** Quando o app diz "nenhuma ocorrência nas fontes consultadas", isso
   quer dizer só que as fontes usadas não registram a combinação. As fontes têm cobertura limitada
   (por exemplo, poucos alimentos).
3. **Traduções.** Os textos clínicos são traduzidos do inglês. Cada texto mostra se foi revisado ou
   não. Texto "não revisado" é rascunho.
4. **Versão da base.** Todo resultado indica a versão da base e a fonte de origem. Bases ficam
   desatualizadas; confira a data.
5. **Privacidade.** O app funciona offline e não coleta nem envia dados.
6. **Finalidade.** Se o uso mudar (distribuir a terceiros, voltar a incluir pacientes, cobrar), o
   enquadramento regulatório (RDC 657/2022 da Anvisa, software como dispositivo médico) precisa ser
   reavaliado antes. Isto não é aconselhamento jurídico.
